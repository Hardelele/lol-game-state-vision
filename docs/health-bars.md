# Классический читатель плашек (#755, этап 1)

Базовая точка и источник псевдо-меток для второй модели
([entity-model-plan.md](entity-model-plan.md)). Код —
`lolvision/health_bars.py`, прогон по кадрам — `tools/read_bars.py`,
тесты — `tests/test_health_bars.py`. Данные: 646 кадров шести роликов
`dataset/videos` (канал Volibear Challenger Replays, 1920×1080).

## Как устроено

* **Поиск.** Нормированная корреляция с шаблоном рамки плашки 123×23 px.
  Заливка ХП, ресурс и цифра уровня в шаблоне замаскированы, поэтому отклик
  не зависит ни от ХП, ни от команды. Шаблон — медиана 457 уверенных
  находок (два прохода; `dataset/health_bar_template.npz`).
* **Порог и проверка.** Кандидаты от 0.45. Ниже 0.75 нужна проверка
  квадрата уровня: тёмный фон (≥60%) и яркая цифра (≥6 px). Она отсекает
  полосы строений и монстров (у них золотая рамка и нет квадрата) и тёмные
  пустые участки сцены.
* **Подавление дублей** — на размер плашки. Шаблон второй раз совпадает со
  сдвигом ~16 px вниз (рамка ХП ложится на рамку ресурса). При окне в
  полплашки такой дубль считался второй плашкой.
* **Где искать.** Под постоянным HUD (боковые панели, низ, чат, лента
  убийств) — нет, под табло и объявлениями — да. Прямоугольник объявлений
  в маске раскладки (y 189–297) появляется ненадолго, а закрывал полосу,
  где плашки бывают чаще всего. Открытие этих областей добавило 321
  плашку (696 → 1017), ложная из них одна.
* **Команда** — по фону квадрата уровня: тёмно-синий или тёмно-красный.
  Виден и при пустой полосе ХП.
* **ХП и ресурс** — доля заливки слева направо. Засечки внутри заливки её
  не обрывают; щит (белый сегмент) в ХП не входит. У безмановых
  чемпионов ресурс 0.
* **Уровень** — ближайший сосед по квадрату уровня целиком (минимум по
  каналам, сдвиг ±2 px) среди 197 проверенных вручную образцов
  (`dataset/health_bar_levels.npz`). Деление на отдельные цифры по порогу
  не работает: две цифры сливаются, тусклая цифра на красном пропадает.
  Кластеризация без разметки путала 5/8 и 0/6/9.

## Результат на dataset/videos

| | |
|---|---|
| Плашек найдено | 1017 на 646 кадрах (619 кадров хотя бы с одной) |
| Кадров без плашек | 27 — в основном не игра (заставки, чёрный кадр) |
| Точность находок (60 случайных + 60 пограничных 0.45–0.75, глазами) | ложных 0 из 120; среди 321 добавленной открытием HUD — 1 |
| Уровень, проверка «оставить один» на 120 размеченных | 119/120 (ошибка — единственный образец уровня 18) |
| Уровень и команда на 60 случайных плашках, глазами | 60/60 |
| ХП | на глаз в пределах нескольких процентов; точная ошибка — по эталону реплея (этап 2) |
| Время | ~200 мс на кадр 1080p на CPU (`cv2.matchTemplate` с маской) |

Из 50 самых неуверенных уровней шесть неверных: три — редкие 17/18 (их
добавил в образцы), три — плашки, найденные со сдвигом ~8 px вправо.

## Что не сделано

* **Имя чемпиона над плашкой.** Над плашкой бывает статус вместо имени
  («CHANNELING», «STUNNED»). Дальше — тот же приём, что для уровня (образцы
  вырезов имён), или имя из состава матча с привязкой по команде и уровню.
* **Сверка с HUD** (боковые панели: уровень и ХП всех десяти) — критерий
  этапа из плана; пока проверено глазами.
* **Полнота** измерена только на глаз по кадрам целиком. Остались
  пропуски у самого края кадра (плашка целиком не помещается) и под
  постоянным HUD.
* **Скорость для live.** 200 мс — только для псевдо-меток. Для live поиск
  переносится на GPU (свёртка шаблоном) или заменяется детектором
  ([entity-model-speed.md](entity-model-speed.md)).
* Маска раскладки для модели камеры закрывает ту же полосу объявлений.
  Для модели камеры это отдельный вопрос, здесь не трогал.
