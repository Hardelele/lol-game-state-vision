# Эталон камеры из Replay API (#754)

Клиент League при просмотре реплея сам знает, где камера. Replay API
(`game.cfg`, `[General] EnableReplayApi=1`, `https://127.0.0.1:2999`)
отдаёт `cameraPosition`/`cameraRotation` и принимает их: камера ставится в
любую точку ключом `/replay/sequence` с `blend: snap` (через `/replay/render`
она едет плавно, ~500 ед./с). Так получаются кадры, для которых положение
камеры известно точно, без миникарты.

Сбор: `tools/replay_capture.py` (пауза, камера в точку, снимок экрана,
запись положения). Сверка: `tools/replay_eval.py`. Данные — `data/replay/`
(в Git не идут), отчёт — `runs/replay_eval/`.

## Замер 2026-10-10

Реплей патча 16.20, 300 кадров: случайные точки равномерно по полю в
моменты 5, 15, 25 и 35 мин; камера по умолчанию (тангаж 56°, FOV 40°,
стандартный зум). Интерфейс реплея тот же, что в обучающих роликах, так
что раскладка `spectator-volibear-challenger` подходит без правок.
«Край» — кадры, где рамка камеры по эталону выходит за миникарту
(119 из 300: равномерная выборка чаще попадает к краям, чем настоящие
ролики). Ошибки — расстояние до эталона в игровых единицах.

**Рамка ↔ камера.** Центр рамки на экране строго линеен по положению
камеры: 58.2 ед./px, остаток 0.3 px RMS (максимум 0.66 px) — это толщина
линии, не шум игры. Рамка 70 × 39 px экрана (68 × 38 в сетке 256 — как
`estimate_box` и находит в роликах). Поле 0…14 800 по x ложится ровно на
миникарту (1654…1908 px). По y — со сдвигом 3.5 px (~205 ед.): центр рамки
выше точки земли под центром экрана. Сдвиг постоянный — обучению не
мешает, но настоящую точку камеры по рамке без поправки не получить.

| | внутри: медиана / p90 / p99 / max | внутри >200 | край: медиана / p90 | край >200 |
|---|---|---|---|---|
| метка (`find_box`, как в build_coords) | 30 / 55 / 80 / 117 | 0% | 1371 / 2261 | 80% |
| рамка с учётом края (`find_box_clipped`) | 31 / 55 / 79 / 81 | 0% | 34 / 150 | 10% |
| модель `cnn-split16-notgame` | 37 / 162 / 6764 / 7297 | 10% | 1177 / 11825 | 80% |

* **Внутри карты метка — только округление**: смещения нет (медиана по
  осям 0 / −1 ед.), разброс 25 ед. по оси, грубых ошибок нет. Оценка #753
  (≈20–25 ед. по оси) подтверждена эталоном.
* **У края нынешняя метка неверна почти всегда**, когда рамка обрезана:
  медиана ошибки 1.4 тыс. ед. Поиск с учётом края чинит большую часть
  (медиана 34), но 10% краевых кадров всё ещё мимо — его надо дорабатывать
  до правки `minimap_camera`.
* **Модель внутри карты близка к метке по медиане** (37 против 30), но в
  10% кадров промахивается на тысячи единиц. Почти все такие кадры — пустой
  лес в тумане войны: случайная камера смотрит туда, куда кастер обычно не
  смотрит. Для честной оценки модели нужна выборка, похожая на ролики
  (камера у событий), — следующий шаг.

Не проверено: другой зум (рамка меняет размер — видно на скриншотах из
практики), другие HUD, кадры с отключённым туманом.

## Исправление поиска рамки и переобучение (2026-10-10)

`lolvision.minimap_camera.find_box_clipped` ищет рамку и за краем миникарты;
оценка — по видимой части периметра (белый пиксель +1, пропущенный −0.3),
граница отрисовки замерена по Replay API. Против эталона (те же 300 кадров)
у края ошибок больше 200 ед. 0% (было 80%), медиана 39 (было 1371).
Ролики против траектории #753 (игровые кадры у края): 16.5% → 0.9%.
Метки `data/coords` пересчитаны `tools/relabel_coords.py` по сохранённым
миникартам (прежние — `data/coords/_labels_v1/`).

Патчевая модель переобучена с теми же настройками (16/4, 40 эпох) —
`runs/patches/cnn-split16-v2`, с головой «не игра» —
`runs/patches/cnn-split16-v2-notgame` (AUC 0.999, как раньше); она теперь
модель live по умолчанию.

| | отложенные ролики, край: медиана / >200 / >1000 | внутри | эталон реплея, край: медиана / >200 |
|---|---|---|---|
| `cnn-split16` (старые метки) | 48 / 33.0% / 6.4% | 28 / 0% | 440 / 66% |
| `cnn-split16-v2` | 35 / 6.5% / 1.0% | 28 / 0% | 48 / 7.5% |

Отложенные ролики — 6011 кадров (1533 у края), оценка по новым меткам.
Эталон — положения камеры, достижимые в роликах (234 из 300, 53 у края).
Внутри карты на эталоне обе модели промахиваются в ~8–10% кадров — пустой
лес в тумане войны, куда кастер почти не смотрит.
